# Task Management System (CLI)

A simple console-based task management system developed in Python. It allows you to register, search, update, and delete tasks with different priority levels.

## 🚀 Features

- **Task Registration:** Includes title, description, and priority (high, medium, low).
- **Full Listing:** View all tasks with their ID, status, and priority.
- **Flexible Search:** Search by exact ID or by partial title match.
- **Status Management:** Update task titles or mark them as "completed".
- **Validations:** Error handling for invalid inputs and non-existent IDs.

## 🛠️ Project Structure

- `functions.py`: Contains the core logic, task list management, and CRUD functions.
- `main.py`: Console user interface and the main execution loop.

## 📋 Requirements

- Python 3.x installed.

## 💻 Installation and Usage

1. Clone this repository or copy the files into a folder.
2. Ensure both files (`functions.py` and `main.py`) are in the same directory.
3. Run the main program:
   ```bash
   python main.py
